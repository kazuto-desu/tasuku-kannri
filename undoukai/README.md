# 未来運動会 準備スケジュール

2027年4月24日(土)開催の「（仮）未来運動会」までの準備タスクを、ガントチャートで管理する Web アプリです。
GitHub Pages で動き、インストールやサーバー契約は不要です。

## できること

| 機能 | 内容 |
|---|---|
| ガントチャート | タスクを開始日の早い順に自動で並べ、日単位の棒で表示。開始日=終了日のタスクは◆(期限・イベント) |
| 色分け | 時期が確定=濃い青、仮=薄い青(点線)、完了=灰色。終了日を過ぎて未完了のタスクは赤字で「遅れ」 |
| 今日・開催日 | 「今日」の線と開催日の列、「開催まで あと○日」を毎日自動で表示 |
| 編集 | 行をクリックして、タスク名・担当・開始日・終了日・時期・状況・メモを編集。追加・削除も可能 |
| 絞り込み | 担当(安部/鈴木)、未完了だけ |
| 印刷 | 「印刷」ボタンで A4 横に縮小して印刷 |
| 共有 | Google スプレッドシート連携で、安部さん・鈴木さんが同じデータを使えます(1分ごとに自動で読み直し) |

## 公開URL

`https://kazuto-desu.github.io/tasuku-kannri/undoukai/`

(リポジトリの Settings → Pages で、公開するブランチがこのリポジトリの既定ブランチ、フォルダが `/ (root)` になっている場合)

## データについて

- 連携していないときは、データは**その端末のブラウザの中だけ**に保存されます。最初は企画段階の22タスクが入っています。
- Google 連携をすると、データは**あなたの Google ドライブのスプレッドシート**に保存されます。リポジトリ(公開)にはデータは入りません。
- 「設定・連携」→「バックアップを書き出す/読み込む」で、JSON ファイルとして保存・復元できます。

## Google スプレッドシート連携(最初の1回だけ)

1. Google ドライブで新しいスプレッドシートを作る(名前は「未来運動会_スケジュール」など)
2. メニュー「拡張機能」→「Apps Script」を開き、[`gas/Code.gs`](gas/Code.gs) の内容を全部貼り付けて保存
3. `SHARED_KEY = 'change-me'` の `change-me` を、関係者だけが知る合言葉に変えて保存
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行:**自分**
   - アクセスできるユーザー:**全員**
   - 「デプロイ」を押し、アクセスの許可を求められたら許可する
5. 表示された「ウェブアプリのURL」(`https://script.google.com/macros/s/…/exec`)をコピー
6. アプリの「設定・連携」に、URL・合言葉・自分の名前を入れて「接続して読み込む」
7. スプレッドシートが空のときは「この端末のデータを送る」を押すと、今のタスクがスプレッドシートに入ります
8. もう1人の端末でも、同じ URL と合言葉で 6. をすると、同じデータが表示されます

スプレッドシートの「タスク」シートには1行=1タスクで保存され、更新日時と更新者も残ります。
`Code.gs` を変えたときは「デプロイを管理」→ 編集(鉛筆)→ バージョン「新バージョン」→「デプロイ」(URLは変わりません)。

## 注意

- 2人がほぼ同時に同じタスクを編集すると、後から保存した方の内容が残ります。
- 通信できないときに保存した変更は「未送信」として端末に残り、次に同期したときに送られます。
- ファイル構成:`index.html`(アプリ本体)、`gas/Code.gs`(スプレッドシート連携用)
